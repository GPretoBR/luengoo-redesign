# Luengoo — redesign

Proposta de redesign da home do luengoo.com (tarot e videncia por videollamada e chat).

Página estática única: abra `index.html` no navegador.

- Paleta noite + dourado, tipografia Fraunces + Manrope
- Hero com experts conectados, filtro de especialidades, tarifas comparáveis, FAQ
- Responsiva (desktop e mobile) e com `prefers-reduced-motion`

As fotos dos experts são carregadas do servidor do Luengoo.
